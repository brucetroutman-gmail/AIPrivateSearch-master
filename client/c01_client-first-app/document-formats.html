⚠️ Currently Unsupported

Apple Keynote: .key files - please export to PowerPoint format

Image Files: OCR processing not yet implemented

Unknown Formats: Clear error messages with conversion recommendations

Performance & Limitations

  • Excel Files: Limited to first 100 rows for performance
  • LibreOffice Conversions: May take 30-60 seconds per file
  • PDF Processing: Speed depends on document complexity
  • Batch Processing: Files processed in parallel with rate limiting
  • Error Handling: Failed conversions preserve original files
