Here is a numbered master list of all 16 test files generated for your cross-country trucking company HR system (President + 2 VPs + 3 secretaries + 5 dispatchers + 50 drivers).
Each includes file name, format, purpose, and key contents.


Employee_Master_List.xlsx

Format: Excel
Purpose: Full company roster (60 employees)
Contents: ID, Name, Position, Dept, Status, Hire/Term, DOB, CDL #/State/Exp, Med Card Exp, Terminal, Address, Phone, Email, Emergency Contact


CDL_Expiration_Report.csv

Format: CSV
Purpose: Track CDL renewal deadlines
Contents: Driver ID, Name, CDL #, Exp Date, Days Until Exp, Status (OK/WARN/EXPIRES SOON)


Drug_Test_Schedule_2026.xlsx

Format: Excel
Purpose: Quarterly random & post-incident test schedule
Contents: Month, Driver ID, Name, Test Type, Terminal, Due By


MVR_Pull_List_Nov2025.xlsx

Format: Excel
Purpose: Schedule annual + birthday-month MVR pulls
Contents: Pull Month, Driver ID, Name, DOB, State, Reason


I9_Audit_Checklist.xlsx

Format: Excel
Purpose: I-9 compliance & e-Verify audit
Contents: ID, Name, Doc A/B, List, Exp, Reverify By, Notes


Hours_of_Service_Violation_Log.csv

Format: CSV
Purpose: Track HOS violations & corrective actions
Contents: Date, Driver ID, Name, Violation, Minutes Over, Action


Benefits_Enrollment_2026.xlsx

Format: Excel
Purpose: Open enrollment dummy data
Contents: ID, Name, Medical/Dental/Vision, 401k %, Life Insurance


Background_Check_Results_2025.xlsx

Format: Excel
Purpose: Annual & pre-employment BG results
Contents: Check ID, Employee ID, Name, Date, Provider, Result, Criminal/MVR/PSP, Notes


Disciplinary_Actions_Log.xlsx

Format: Excel
Purpose: Progressive discipline tracking
Contents: Action ID, Date, ID, Name, Type (Verbal/Written/Suspension/Term), Rule, Description, Manager, Follow-Up


Safety_Incident_Report_Register.csv

Format: CSV
Purpose: DOT-reportable & preventable incidents
Contents: Incident ID, Date, Driver ID, Name, Type, DOT?, Injury?, Fatality?, Preventable?, Root Cause, Action


PSP_Report_Summary.xlsx

Format: Excel
Purpose: FMCSA PSP crash & violation scores
Contents: Driver ID, Name, Pull Date, Crash Indicator, Score, Violations, Notes


Random_Drug_Alcohol_Testing_Pool_2025.xlsx

Format: Excel
Purpose: FMCSA 25% random testing compliance
Contents: Quarter, Date, Driver ID, Name, Test Type, Result, Lab, Collector


Driver_Qualification_File_Checklist.xlsx

Format: Excel
Purpose: DQ file audit per FMCSA 391.51
Contents: Driver ID, Name, File Complete?, App/CDL/Med/MVR/Training/Review, Notes


ELD_Malfunction_Log.csv

Format: CSV
Purpose: FMCSA 395.34 malfunction reporting
Contents: Date, Driver ID, Name, ELD Serial, Terminal, Malfunction, Reported To, Resolved, Duration


Annual_DOT_Audit_Prep.xlsx

Format: Excel
Purpose: Compliance dashboard for DOT audit
Contents: Category, Required, Completed, %, Due By, Owner, Status


Full_50_Drivers_Dataset.xlsx

Format: Excel
Purpose: Complete 50-driver roster with formulas
Contents: ID, Name, Status, Hire, DOB, Age (formula), CDL #/State/Issue/Exp, Days to CDL Exp (formula), Med Card Exp, Days to Med Exp (formula), Terminal, Full Contact Info
