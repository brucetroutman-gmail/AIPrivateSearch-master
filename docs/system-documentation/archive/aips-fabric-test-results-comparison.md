## Test 2: Fabric-Enhanced Prompt

**Source file**: `aips-frabric-test-prompt.md`

**Command**: `node test-fabric.mjs "what are the founding principles of the USA" qwen2.5:3b`

**Fabric Enhanced Prompt** (generated by improve_prompt pattern):
```
# Founding Principles of the United States

Please provide a comprehensive explanation of the founding principles of the 
United States. Organize your response as follows:

1. Core Principles: List and briefly define the 3-5 most fundamental principles
2. Historical Context: For each principle, explain which founding documents or 
   thinkers influenced it
3. Practical Implementation: Describe how each principle was reflected in the 
   U.S. Constitution or the Bill of Rights
4. Modern Relevance: Briefly note how each principle remains relevant today

Keep your response detailed but organized, using clear headers and bullet points 
where appropriate. Aim for approximately 3-4 paragraphs per principle.
```

**Fabric time**: 2.56s

**Ollama Response** (structured, with sub-sections per principle):
- Liberty — Definition, Historical Context (Locke), Practical Implementation (1st/5th Amendments), Modern Relevance
- Democracy — Definition, Historical Context (Paine, Madison), Practical Implementation (electoral process), Modern Relevance (Voting Rights Act)
- Federalism — Definition, Historical Context (Montesquieu, Locke), Practical Implementation (10th Amendment), Modern Relevance (healthcare, immigration)

**Ollama time**: 58.48s  
**Total time**: 61.04s

## Verdict

The Fabric enhancement produces a significantly higher quality, more structured, and more academically rigorous response. The tradeoff is:

- **Breadth**: Raw prompt covers 8 principles vs 3 with Fabric (Fabric prompt instructed 3-5)
- **Depth**: Fabric response is far more detailed and useful for research
- **Time**: 61s total vs near-instant for raw

**Key insight**: The enhanced prompt gave Ollama explicit instructions on structure, depth, and sourcing — and the model followed them precisely. The `improve_prompt` pattern is a generic fallback. A collection-specific pattern (e.g., `enhance_USA-History`) built from `safeDomainContext.json` will produce even better results by adding domain vocabulary and document-specific context.
